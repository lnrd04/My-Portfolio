About the Project

Vermilion Noir is a self-made static website project designed in Figma as my third website. This project focuses on translating the UI design into a functional layout, emphasizing visual structure, spacing, and modern HTML/CSS implementation.

Key Features

  • Layout and visual structure implemented with modern HTML and CSS
  • Layout and design for Perfumes
  • Clean structure with consistent styling
