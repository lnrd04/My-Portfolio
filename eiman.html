eiMAN

A UI/UX-focused web project designed to guide developers in recreating the interface from Figma.

About the Project

eiMAN is a fully designed interface based on Figma prototypes. This project was created to help web developers implement a clean and consistent layout, replicating spacing, visual hierarchy, and interactive elements. The focus is on translating Figma designs into a functional static website using modern HTML and CSS.

Key Features

  • Designing a UI/UX in figma for eiMAN website
  • Structured layout and design for developer reference
  • Clean, consistent styling
