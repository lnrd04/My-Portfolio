About the Project

This project is a static website designed for a construction firm. The goal was to create a professional online presence that showcases their services, previous works, and contact information with a focus on trust and durability.

Key Features

  • responsive in mobile screens
  • Service showcase with custom-styled cards
  • Contact form integration for lead generation
  • Smooth scroll navigation and modern UI elements
