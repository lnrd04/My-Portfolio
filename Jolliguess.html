About the Project

Jolliguess is a self-made static website project inspired by the design and layout of the Jollibee website. This project was created for practice purposes, focusing on recreating visual structure, spacing, and overall user interface using modern HTML and CSS techniques.

Key Features

  • UI clone inspired by the Jollibee website
  • Layout and design replication for practice
  • Clean structure with consistent styling
